# 提取、复核与开源后备路径

本机默认：FFmpeg 抽帧/音轨，whisper.cpp 本地转写，macOS Vision 识别完整画面文字及二维码，Codex 阅读上下文作分平台判断。脚本自身不连接平台审核接口，也不自动上传视频。

## 默认运行

`extract_video.py`：标准库 Python，必须有 `ffmpeg`、`ffprobe`。macOS 自动编译同目录 `ocr.swift`。语音需 `whisper-cli` 和多语言模型（不要使用 `.en` 英语专用模型识别中文）。

参数：`--fps 2` 为每秒约2帧加场景切换；`--fps 0` 为逐帧文字扫描；`--model /模型路径`；`--language zh` 或默认 `auto`；`--subtitle /字幕.srt` 可多次使用。`--skip-asr` 和 `--skip-ocr` 只用于诊断或任务明确不需要该通道，不能用来假装完成全部检查。

输出：
- `manifest.json`：视频摘要、完整音轨/字幕轨状态、帧数量、抽样间隔、失败原因。
- `evidence.json`：不同通道原文和时间，不覆盖彼此。
- `ocr.jsonl`：逐帧文字、置信度、二维码信息及方框位置（左上角为原点，0至1归一化）。
- `frames/`、`frames.json`：原分辨率帧及真实显示时间，自动处理正常的视频旋转标记。
- `speech-*.srt/json`、`audio-*.wav`：独立音轨证据。
- `candidates.json`：辅助线索，不是最终审核结果。

必须检查每条失败记录。OCR空白可能是“没有文字”也可能是“没有识别出”，需看原图；二维码未检出同理。没有词表命中不代表无语义风险。不要给自动识别置信度包装成平台违规概率。

## 本地依赖不可用时

优先用环境已有的本地语音/图片识别能力，再考虑开源：

| 问题 | 可用后备 | 注意 |
|---|---|---|
| 没有 whisper-cli | ggml-org/whisper.cpp 或 SYSTRAN/faster-whisper | 安装来源使用项目官方或可信包仓库；记录所用模型；长音频分段要加回时间偏移 |
| macOS Vision不可用/中文识别差 | PaddlePaddle/PaddleOCR、RapidAI/RapidOCR | 必须扫描全画面；只裁底部字幕会漏地址栏 |
| 硬字幕太密、不断变化 | YaoFANGUK/video-subtitle-extractor | 输出字幕之后仍要补全画面检查 |
| 抽样漏一闪而过的文字 | `--fps 0` 或单独截取片段逐帧 | 截片起点要加回原视频时间；逐帧OCR仍会读错小字 |
| 语音/字幕打架 | 回听 WAV 并看同一时刻原帧 | 分别保留真实声音和字幕，不以字幕自动修正声音证据 |
| 方言、音乐、多人重叠 | 更大语音模型、人工听校、已授权识别服务 | 识别不确定就是待核，不按模型猜出的文字定违规 |

模型官方获取方法见 whisper.cpp 项目的 `models/download-ggml-model.sh`，本次核实其来源为 `https://huggingface.co/ggerganov/whisper.cpp`。不要把测试用 `for-tests-ggml-tiny.bin` 当作完整语音模型。技能便携压缩包不包含数百兆的模型；本机安装可保留模型供后续使用。

## 必须人为复核的事项

1. 地址及不当用语命中，先看清原帧或回听，不直接套剪辑。
2. 否定句如“不能保证治愈”与“保证治愈”不同；引用骗局与招揽骗局不同。
3. “example.com”按用户零网址要求要提醒，但 `.mp4`、`index.html`、`3.14` 不是同一种证据。
4. 给剪辑/遮挡范围前确认完整出现时段及屏幕区域，字幕轨不是画面已显示的证明。
5. 版权、真实体验、专业资格、AI制作来源、发布设置不能只从成片确定。

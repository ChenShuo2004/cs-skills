# 参考资料导航

## 来源与实现

| 文件 | 用途 |
| --- | --- |
| [sources.json](sources.json) | 来源编号、获取状态、查阅时间和条款摘要 |
| [source-refresh.md](source-refresh.md) | 获取与刷新官方正文的方法，以及已知缺口 |
| [extraction.md](extraction.md) | 提取依赖、输出文件、采样范围与开源后备路径 |
| [report-and-tests.md](report-and-tests.md) | 报告示例与需要人工复核的验收场景 |
| [github-projects.md](github-projects.md) | 类似开源项目与参考边界 |
| [local-reference-review.md](local-reference-review.md) | 历史本地参考的方法取舍与验证记录 |

## 配置与兼容入口

- [user-profile.json](user-profile.json)：公开默认配置，现有程序继续从此路径读取；可选配置见 [配置说明](../profiles/README.md)。
- [checklist.md](checklist.md)：旧清单入口，指向 [通用清单](../rules/common/checklist.md)。
- [platforms.md](platforms.md)：旧平台入口，指向 [规则目录](../rules/README.md)。

来源记录的日期与获取状态以文件内容为准；本导航不表示已重新核实来源。旧入口保留，方便已有链接继续使用。

# 通用检查清单

以下是发布前检查项，不是“一碰词就违规”的词表。来源编号对应 `../../references/sources.json`。每项需结合前后语境、平台、发布场景、证据强度判断；无材料就写待核实。规则核查日期：2026-09-06。

## 通用内容底线

| 编号 | 检查点 | 如何判断 / 修改方向 | 依据 |
|---|---|---|---|
| C01 | 国家安全、秘密、暴恐、违法犯罪动员 | 看实际行为与传播目的；正常历史、新闻讨论不等同于动员或泄密 | L01、D02 |
| C02 | 地图、国家标识、英雄烈士 | 查实际地图与标识；违法贬损或商业借名背书需处理，文字转写不能确认地图完整性 | L01、L02、B01 |
| C03 | 民族、种族、性别、地域等歧视煽动 | 区分观点讨论与针对群体的贬损、仇恨、引战 | L01、D01；X05为转述 |
| C04 | 邪教、迷信、伪科学牟利 | 区分文化介绍与把玄学说成客观疗效、承诺改命并收费 | L01、D01、B01 |
| C05 | 色情、性交易、露骨性描写 | 检查语音、字幕、音效与画面组合，科普/艺术也需看呈现尺度 | L01、D02 |
| C06 | 性暗示、擦边、偷拍或非自愿传播 | 不能只检查裸露；不当运镜、暗示话术、偷拍传播也可能构成风险 | L01、X01、B01 |
| C07 | 血腥、恐怖、残忍、虐待动物 | 识别视觉证据和强调方式；必要信息可裁去细节并补语境 | L01、D01 |
| C08 | 自伤、自杀鼓励或方法展示 | 区分求助/预防与鼓励、示范；禁用“加提示就能发”的机械判断 | D01 |
| C09 | 危险挑战、危险驾驶、不安全模仿 | 看行为可模仿性和安全条件；提示语不自动修复危险示范 | L01、D01、X01 |
| C10 | 违禁品、赌博、诈骗、非法服务 | 区分反诈揭露与推广交易；所谓资料、教程也要看实质用途 | L01、D02 |
| C11 | 侮辱、诽谤、网暴、人肉、骚扰 | 负面评价应有事实基础；不组织围攻，不曝光私人信息 | L01、D01 |
| C12 | 隐私与身份信息 | 查手机号、邮箱、住址、证件、银行卡、病例、账号密码、聊天记录；公开商业地址与他人住址分开 | L01、D01、X02 |
| C13 | 未成年人隐私与权益 | 查脸、校服、校名、定位组合；不以保护对象被识别为代价进行“曝光” | D04、B01 |
| C14 | 利用儿童吸流量、带货、打赏或成人化 | 查看商业目的、表演与消费引导；普通家庭记录不自动定违规 | D04、B01 |
| C15 | 谣言、伪造事实、虚假新闻 | 核实来源、日期、地点、完整上下文；旧视频不能冒充当前事件 | L01、D02、B01 |
| C16 | 演绎、摆拍、翻拍冒充事实 | 查是否可能误导，需要时明确演绎说明；声明不豁免恶意造谣 | D01、B01 |
| C17 | 灾难消费、恶意煽动、挑起对立 | 查是否歪曲公共事件、羞辱当事人或用冲突引流 | L01、D07；X05为转述 |
| C18 | 标题党、封面误导、图文无关 | 对照标题/封面与实际视频；没有外部封面则标未检查 | L01、B01、X01 |

## 原创、权利与真实身份

| 编号 | 检查点 | 如何判断 / 修改方向 | 依据 |
|---|---|---|---|
| C19 | 影视、音乐、图片、素材、字体、录屏版权 | 要求必要授权线索；“网上找到”“注明出处”不自动获得授权，不能仅凭音频识别证明版权 | D01、X02、B01 |
| C20 | 搬运、抄袭、重复稿件与原创声明 | 区分合理引用、原创、翻译、转载；判断规则适用，不能杜撰固定重复次数 | B01、D01 |
| C21 | 冒充机构、认证、专业身份、虚假人设 | 查身份主张证据；表演角色与真实资格分开 | D01、X04、X05 |
| C22 | AI生成、换脸、拟声、数字人 | 已知使用生成合成内容时主动声明并用平台标识；未知来源只列待核，不能因“看着像AI”定性 | L05、B04、D02 |
| C23 | 恶意移除标识、AI造假与非法AI产品 | 不推荐删水印绕审；合法工具介绍与违规产品教程分开 | L05、B05 |
| C24 | 虚构体验、伪造测评、数据、证书 | 检查是否真正体验、样本条件、商家介入与可验证依据 | X01、X05、L02 |

## 网址、地址与导流（检查通道不能只限字幕）

| 编号 | 检查点 | 如何判断 / 修改方向 | 依据 |
|---|---|---|---|
| C25 | 完整网址、裸域名、短链 | 检查 `https://`、`www`、域名及路径。正常教程与导流分开；用户严格配置另算 | X01 3.2、D01 34、B02、用户要求 |
| C26 | 疑似网址与拆分拼接 | 查空格、全角点、中文“点”、换行、口述字母、跨帧拼接；原样保留并回看，不建议用其绕审 | 同 C25；识别方法为本技能推断 |
| C27 | 浏览器地址栏、演示代码、网页截图 | 查顶部地址栏、悬浮链接、终端输出；代码文件名/版本号未必是网址。零展示配置仍需检查真实域名 | 用户要求；是否官方风险取决于 C25 |
| C28 | 邮箱、微信/QQ、电话、社交账号 | 单独提到工具名不等于提供联系方式；识别加好友、询价、购买等引导 | X01 3.2、B02、D01 33/34 |
| C29 | 具体住址、收货地址、门牌、定位 | 隐私泄漏、个人联系地址和公开店址分别判；具体地址按用户配置提醒删改 | X01 3.2、D01 13、L01、用户要求 |
| C30 | 二维码、小程序码、口令、网盘提取码 | 解码仅提取不访问；完整可扫描、部分可识别和装饰图形分开 | X01 3.2、B02、D01 34 |
| C31 | 水印、片尾卡、页脚、名片 | 通道隐藏不改变导流实质；回看短暂出现的内容 | X01 3.2、B02；用户要求 |
| C32 | 私信、主页、评论区、搜索引导组合 | “私信我”不是通用合规替换词；结合后续站外交易与实际承接方式判断 | X03 3.4（投放）、X06转述、D01、B02 |
| C33 | 站外付款、低价私聊、绕开官方交易 | 看有无平台认可渠道及实际商业目的；不能用“B站允许网址”豁免 | B02、X01/X06、D01；D05专项需补查 |
| C34 | 恶意链接、盗版/色情/诈骗入口 | 普通网址本身不一定违规，指向恶意/违法内容的链接四平台均需复核 | D01 34、B01、X01、W01 4.8.3/5.6 |

## 商业广告、带货与专业行业（先确认场景）

| 编号 | 检查点 | 如何判断 / 修改方向 | 依据 |
|---|---|---|---|
| C35 | 商业合作、利益相关、广告声明 | 推销与购买方式、赞助关系、平台报备分开检查；片内没有声明不证明发布页没标 | L02、L03、B01、X05 |
| C36 | 绝对化词与保证效果 | “我最喜欢”不等于“全网最佳”；应判断是否广告及是否误导，不能仅删一个字 | L02、L04 |
| C37 | 数据、排名、专利、论文、权威背书 | 来源真实、适用对象/年份/样本/统计范围完整；不虚构销量第一 | L02、L06 |
| C38 | 大字承诺、小字限制或免责 | 重要条件清晰可读且与主张一致；角落小字、快速闪过不当然有效 | L06 |
| C39 | 假效果、假对比、过度美化 | 区分创意演示与真实承诺；AI示意不能冒充实测结果 | L02、X01、D01 |
| C40 | 原价、优惠、赠品、库存、倒计时 | 对照商品页和实际活动条件；没有商品页则待核，不能宣布已核 | L02、X01；平台电商专项需补读 |
| C41 | 口播、字幕、实物与商品链接不一致 | 核对型号、数量、服务范围与有效期；不能只改字幕保留相反语音 | L02；B03仅课程 |
| C42 | 医疗诊断、处方、治愈、偏方 | 先分科普与服务营销，再核身份资质、科学依据、适用人群和风险 | D03、L02、X04 |
| C43 | 食品、保健品、化妆品宣称治病 | 功效必须符合适用类别和允许范围，不能把普通商品说成药品 | L02、L03、X03 |
| C44 | 健康科普同时给相关商家地址/联系方式 | 这是明确受限场景，不等于所有生活类视频都禁止地址 | L03 第8条 |
| C45 | 医美、减肥、身材焦虑、未成年消费 | 科普、体验、营销分别核；具体准入需查平台当前行业规则 | X03、X04、D03 |
| C46 | 投资收益、荐股、内幕、保本、网贷 | 科普和招揽分开，核资质及真实依据；“不构成投资建议”不修复实质承诺 | L02 第25条、D01、X04 |
| C47 | 培训、考证、保过、就业承诺、论文代写 | 核准入和真实性，考试作弊不能包装成普通课程 | L02 第24条、X03、B03 |
| C48 | 法律、房产、旅游等资质型服务 | 不因提到领域就判违规；提供专业服务、招揽客户时核相应资质与平台认证 | X04、D01、B01 |
| C49 | 招聘、副业、返利、刷单、成功学暴富 | 查是否虚假收益、先付费骗局、违法交易或贬低劳动 | D01、X03、L01 |
| C50 | 未批准/禁止推广的商品服务 | 查看具体平台、广告/电商场景、商品类别及新规；禁投不一定等于不能讨论 | X03、D01、D05 |

## 平台秩序、质量与发布设置

| 编号 | 检查点 | 如何判断 / 修改方向 | 依据 |
|---|---|---|---|
| C51 | 诱导互动、福利、抽奖、涨粉 | 正常互动与虚假福利/强制互动/赌博分别判断；投放规则可能更严 | X03 3.6（投放）、D01 |
| C52 | 买赞、刷量、账号交易、同质垃圾内容 | 单条低播放不能推出违规；根据可见行为与资料判断 | L01、D01、B01 |
| C53 | 外语字幕、歧义、音画不一致 | 原语言转写与中文字幕对照，广告物料与普通投稿要求分开 | B01投稿规范、X03（投放） |
| C54 | 黑屏、花屏、低清、遮挡、错误比例 | 作为质量/投放风险，不能把技术信号直接定内容违法 | X03（投放）、B01 |
| C55 | 标签、分区、无关热点、错误转载类型 | 必须取得实际发布信息才能判断，不能从成片猜标签 | B01、D01 |
| C56 | 未成年人/演绎/素材来源/风险提示等声明 | 依据实际场景补充；一般提醒不能替代依法应有的标识或资质 | B01、D02、D03、L05 |
| C57 | 付费加热、投放、带货资格 | 普通发布可见不等于能投广告；禁止把加热不通过说成内容封禁 | X03、D05；各平台当次投放规则 |
| C58 | 主页、置顶评论、简介、商品页 | 若未提供，列未检查；关联导流线索应提示补充后复审 | X04、B02、D01 |

专项目录不等于覆盖所有行业条款：直播连麦、特殊商品、财经/医疗执业、微短剧备案等任务出现时，必须按相应平台当前专项规则补查，不以普通视频清单直接作出完整结论。

这些是跨平台的检查问题，不表示各平台规则完全相同。最终叠加 [单平台规则](../README.md)，商业、课程等条目只在对应场景应用。

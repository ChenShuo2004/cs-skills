# `cs-github-push` 录屏脚本

这段 16:9 中文讲解面向第一次把 Skill 推到 GitHub 的用户。画面录制公开仓库页面：仓库首页、`cs-github-push` 目录和首次加入该 Skill 的远端提交。字幕解释工作流；视频**没有录制一次新的真实推送**，远端提交页仅用于展示可核验的 GitHub 结果。

| 时间 | 画面 | 字幕重点 |
| --- | --- | --- |
| 0–6 秒 | `cs-skills` 仓库首页 | 本地提交不等于 GitHub 已更新 |
| 6–11 秒 | `cs-github-push` 目录 | 确认仓库、分支和范围 |
| 11–30 秒 | 首次加入 Skill 的提交详情，滚动展示改动 | 来源与验证、精确提交、检查远端 |
| 30–46 秒 | GitHub 远端提交页 | 比对 SHA，给出调用语句 |

## 中文口播

> 本地改好了，为什么 GitHub 上还是旧版？因为本地提交，不等于远端发布。现在用 CS GitHub Push，完成一次可核验的仓库交付。第一步，检查仓库、分支和改动范围，确定本次要提交哪些文件。第二步，核对来源，运行相关验证，只暂存指定文件。第三步，先检查远端有没有新提交，再推送，避免覆盖别人的工作。最后，比对本地和 GitHub 的提交编号。两边一致，才算真正推上去了。你只要说：用 CS GitHub Push，把这次改动推到 GitHub，并核验远端提交。

## 复用方式

更新视频时，先核对 [`SKILL.md`](../../cs-github-push/SKILL.md) 的实际流程，再录当前仓库页面；字幕、口播与画面都应对应真实状态。录完检查时长、分辨率、音轨、首尾画面与字幕遮挡。推送成片后，比对远端提交 SHA。

# CS Skills README 优化 · 代码渲染版

## 目标与一句话

用一个真实仓库说明：README 优化先核对事实，再按新人阅读路径重排，最后验证并交付。观众看完能复制 `$cs-clean-code` 的调用句。

## 规格与素材

- 1920 × 1080，30 fps，73.24 秒，H.264/AAC。
- 口播沿用 8 段 Fish Audio `s2.1-pro-free` 配音；音色 ID 由用户提供，密钥在仓库外。
- 事实证据：历史 README `caacd86`、改版提交 `0b27495`、`AGENTS.md` 和制作时的主分支截图。
- KAI 猫代码组件和已有 KAI 图来自本仓库所安装的 `cs-code-video` 资源及用户的 KAI 教程片素材。

## 导演与版式

核心冲突是“信息完整但找不到入口”。用**两份页面的路径对照**作视觉隐喻：旧页作为截图证据，新结构由代码画成可读的大卡片。深色网格承载讲解，KAI 蓝给流程，信号橙只标转折；白色证据卡保留真实页面。每个镜头只呈现一个判断，文字在安全区内，并按配音先后出现。没有默认淡入淡出；内容在每段内逐项出现，场景切换用硬切。

## 实现与验收

`code-film.html` 暴露 `window.render(t)`；Playwright 按任意时间取帧，FFmpeg 编码。`make_audio.py` 依据 `timeline.json` 放置配音并根据 `audio-cues.json` 合成轻音效。先查关键帧，再跑低清全片，再渲 1080p 最终版。历史截图明确标版本，制作时截图不冒充仓库最新状态。完整命令见 [VO.md](VO.md)。

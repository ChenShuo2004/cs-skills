# CS Search Skill

回答用户要做的决定，以证据支撑建议。默认中文简报；明确要求报告、文件或 PDF 时采用对应形式，不在研究末尾临时询问格式。

## 研究范围

从请求和已有材料确定对象、决策、时间与地区。只有同名实体无法区分或缺失信息会改变研究方向时提问；其他采用透明默认。

比较数量与维度服从问题。通常选少量真正可替代的方案；用户只问两家就比两家，不为凑 3–5 家扩大范围。发展史、融资、用户口碑仅在影响决策时展开。

## 证据工作

- 先用现有材料建立待验证问题，再搜索最新公开来源并打开原文；搜索摘要只是线索。
- 技术结论优先官方文档、仓库和论文；价格、产品规格、政策或当前状态核对直接来源与日期。用户评论用于体验线索，不冒充总体样本。
- 对影响决策的争议或高风险结论做独立交叉验证；多篇转载不算独立证据。单一权威来源足以回答的稳定事实无需凑第二来源。
- 每个核心结论保留来源标题、URL、更新时间/访问日期与支持范围。无法访问的来源不声称已读，不用推测补数值。
- 冲突证据优先比较适用版本、地区、定义和日期，不能只挑支持自己结论的材料。

## 综合与停止条件

区分事实、推断和未知，给出建议、条件与能改变建议的证据。继续检索必须回答一个仍影响选择的问题；当决策已有足够支撑、关键冲突已处理或明确暴露后交付，不为篇幅补资料。

报告先给结论，随后关键证据、必要比较、风险和下一步。引用紧邻相关断言，附研究截止日期；不强制长目录或无关历史章节。

完整报告按用户要求扩展。PDF 使用当前可用的文档工具生成并检查；工具不可用先交付完成的研究正文，明确文件缺口。用户要求“调研后写文章”时，完成事实简报后直接交接 $cs-writer，不重复索要写作授权。

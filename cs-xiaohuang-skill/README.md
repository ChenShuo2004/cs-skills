# 小黄正文配图

> 把中文内容中最重要的判断、关系和转折，画成一张张由小黄参与行动、带中文手写标注的正文配图。

小黄不是通用的黄色卡通角色。它有固定的暖黄色梨形身体、橙色爱心天线、椭圆眼睛、腮红和细手脚；每一张图里，它都要亲自完成解释概念的关键动作。

![小黄角色参考](assets/reference-xiaohuang.png)

## 它解决什么

`$cs-xiaohuang-skill` 先从文章里找出真正值得被理解的**认知锚点**，再把一个判断、变化、关系或隐喻变成读者一眼能看懂的画面。

它适合文章、公众号、博客、Notion 和知识型内容的正文配图；不用于商业 KV、复杂架构图、可编辑 SVG，或把多个观点塞进同一张图的 PPT 式信息图。

## 固定视觉语言

- 16:9 横版、暖白底、黑色轻手绘线条和大量留白。
- 小黄必须是动作主角，不能只在角落装饰。
- 红橙色标记问题、警示或结果；蓝色标记反馈、状态或下一步。
- 每张只解释一个关系，标注要短、要可读。

## 七张示例流程

以下示例用于校准小黄的身份、构图和标注方式；每次创作都应根据当前内容重新设计隐喻。

### 1. 抓住一个核心动作

从信息堆里先照亮读者最该理解的那一步。

![抓住一个核心动作](assets/examples/01-cognitive-anchor.png)

### 2. 一个画面，只说一件事

剪开打结的信息，只留下一个重点。

![一个画面只说一件事](assets/examples/02-one-idea.png)

### 3. 把关系画出来

把分散的素材连接起来，让结论自然显现。

![把关系画出来](assets/examples/03-relation-reveal.png)

### 4. 给重点留空

删去干扰元素，让真正的重点出现。

![给重点留空](assets/examples/04-negative-space.png)

### 5. 把抽象变成看得见

把难懂的概念换成直观的物理隐喻。

![把抽象变成看得见](assets/examples/05-metaphor-translation.png)

### 6. 标注越短越好

用少量关键词帮助理解，不用长文替代画面。

![标注越短越好](assets/examples/06-concise-labels.png)

### 7. 最后检查一遍

确认画面清楚、标注可读、小黄身份正确后再交付。

![最后检查一遍](assets/examples/07-quality-check.png)

## 快速调用

先只做配图规划：

```text
$cs-xiaohuang-skill 先不要生图。请找出这篇文章最值得配图的 4 个位置，输出 shot list：每张写清插入位置、核心意思、小黄动作、构图和中文标注词。
```

直接生成：

```text
$cs-xiaohuang-skill 把下面这篇文章生成 4 张小黄正文配图。每张只讲一个判断，16:9 横版、白底黑线、保留小黄爱心天线和暖黄梨形身体，配简短中文手写标注；先给 shot list，再逐张生成。
```

## 使用原则

让图解释文字中最难理解的那一步，而不是机械地给每一段补一张图。小黄的动作、物件和标注必须共同服务于一个清楚的判断。

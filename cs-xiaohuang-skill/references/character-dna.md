# 小黄角色 DNA

小黄就是“有温度”的固定角色，也可称为“温度种子”。每次生成、修改或评估角色时，以本文件和 `../assets/reference-xiaohuang.png` 为身份准则。

## 基础轮廓

- 主体是一个不规则、微倾斜的暖黄色软团，接近偏椭圆种子与柔软水滴的结合，但不是标准梨形。
- 左下略鼓、右上略收，重心微偏，轮廓不能过度对称。
- 身体看起来柔软、轻盈、有弹性；禁止圆球、鸡蛋、普通水滴、梨子水果或动物身体。

提示词可使用：

```text
asymmetric warm seed blob, soft irregular silhouette, slightly leaning organic form
```

## 顶部与面部

- 顶部是一根细长、略弯的天线，末端必须是暖橙黄色的空心爱心轮廓；爱心通过细线从身体长出，不能直接贴在头顶。
- 保留两只间距偏宽的黑色纵向椭圆眼、极简小弧线嘴和淡橙色腮红；不画鼻子。
- 禁止实心红心、叶子、花朵、王冠、火焰、普通触角球、大眼动漫、玻璃眼、复杂眉眼和写实五官。

## 四肢与连接爱心

- 四肢使用极细黑色线条，末端高度简化；默认不画鞋子、手套或人类手掌细节。
- 标准形象的右侧手臂可以延伸或托起一个暖橙色空心爱心，代表连接、传递和点亮。普通生活场景可移除；连接、陪伴、共创和品牌说明主题优先保留。

## 颜色

| 用途 | 色值 | 说明 |
| --- | --- | --- |
| 主体基准 | `#F6B72A` | 暖金黄 / 蜂蜜黄 |
| 主体高光 | `#FFD86A` | 温和亮部 |
| 主体深部 | `#E99A1B` | 体积与手绘层次 |
| 辅助暖橙 | `#F59A23` | 爱心、连接线、少量强调 |
| 墨黑 | `#151515` | 五官和四肢 |
| 暖白背景 | `#FFF9EF` | 默认背景 |

保持“主体暖黄 + 黑色极简五官四肢 + 少量暖橙”，避免荧光黄、廉价渐变、赛博蓝和彩虹扩色。

## 品牌语义与优先级

小黄代表连接、陪伴、点亮、降低距离、让知识进入生活、让好东西真正被人使用。画面优先表现连接、递出、点亮或陪伴，而不是静止卖萌。

当要求发生冲突时，按以下顺序决策：

1. 已确认的角色身份锚点；只有用户明确确认创建新角色时才可改变。
2. 用户当前明确指令中的可变项。
3. 当前任务的结构与语义。
4. 风格参考、媒介和装饰细节。

# 质量检查

## 所有任务的身份必过项

- [ ] 轮廓是不规则、微倾斜的暖黄色种子形生命体，左下略鼓、右上略收；不是标准梨子、鸡蛋、圆球或水滴。
- [ ] 顶部是一根细长弯曲天线，末端为暖橙色空心爱心；没有叶子、花朵、王冠、火焰或实心红心。
- [ ] 保留间距偏宽的黑色纵向椭圆眼、小弧线嘴、淡橙腮红与细黑四肢；没有鼻子、动漫大眼、鞋子、手套或复杂人类手掌。
- [ ] 主体为暖黄，五官与四肢为墨黑，只使用少量暖橙强调；未扩成彩虹、荧光黄、赛博蓝或廉价发光。
- [ ] 角色正在完成有意义的动作，不是静止卖萌或角落装饰。

## 正文配图必过项

- [ ] 是 16:9 横版、干净暖白底和足够留白。
- [ ] 黑色线稿轻、自然；小黄承担解释观点的核心动作。
- [ ] 一张图只讲一个关系，中文标注短且不超过 6 处。
- [ ] 画面不复制旧构图，能一眼理解但不做成 PPT 或说明书。

## 品牌 IP 延展必过项

- [ ] 用户要求的动作、场景、媒介或风格已经完成，且身份锚点仍完整。
- [ ] 3D 只改变体积、材质与光线；未变成毛绒、针织、金属、过度玻璃化或写实水果。
- [ ] 风格迁移只迁移视觉语言，没有复制参考角色的身份元素。
- [ ] 联名角色各自可辨，没有合并轮廓、交换标志物或附加未要求的角色、文字、Logo 与水印。

## 失败信号与迭代

- **太满或太像 PPT**：删除节点、卡片、箭头和标题，只留一个动作。
- **小黄太可爱或没参与**：改成解决、搬运、筛选、修复、连接或点亮问题的动作主体。
- **中文错字多**：先减少标注，必要时只局部编辑错误文字。
- **多版本结构雷同**：改轮廓比例、重心、凹凸、肢体位置和天线方向，不只换材质。
- **只有一个局部失败**：固定全部不变量，只编辑失败部位；**两个及以上身份锚点失败**：重新设计，不继续微调。

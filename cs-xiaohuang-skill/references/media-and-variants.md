# 小黄媒介与延展规则

## 默认 2D 原生版

- 使用手绘蜡笔、油画棒和彩铅混合质感，保留可见颗粒但保持干净轮廓。
- 使用柔和暖白背景和轻微蜂蜜黄内发光，保留手工边缘，避免工业矢量感。
- 禁止过度 3D、毛绒玩具质感、廉价外发光和复杂背景。

## 3D 转换

必须保持原始不规则种子轮廓、空心爱心天线、黑色纵向椭圆眼、小弧线嘴、细黑四肢和暖黄色主体。

材质优先级：

1. 哑光软胶 / soft vinyl。
2. 半透明温润树脂。
3. 细腻磨砂橡胶。
4. 陶瓷，仅在用户明确要求时使用。

使用柔光棚拍、暖白无缝背景和轻微接触阴影。禁止毛绒、长毛、针织、金属、过度玻璃化、写实皮肤和梨子水果细节。

## 黑白与共创风格

可以把主体降为白色黑线或黑白线稿，但必须保留小黄自己的外轮廓和顶部爱心天线；可使用略抖动的手写黑线与大面积留白，只保留极少量暖橙作为品牌锚点。

统一画风不等于复制对方角色。只迁移线条、色彩、构图、场景复杂度和材质；不要迁移对方的身体轮廓、标志性五官、独有配饰或标志性动作。

## 形状、动作与情绪

多版本必须改变轮廓比例、重心方向、上窄下宽或左右偏移、凹凸与身体张力、肢体位置和天线弯曲方向，不只换材质。优先提供四个结构差异明显的方向：偏瘦略倾斜的种子、矮宽低重心的团、上鼓下收的泡、柔软扁平的片。

推荐动作：挥手、抱心、递出爱心、跑步、坐下、思考、探头、抱住物体、拉连接线、点亮物体、递知识卡片、陪伴另一个角色完成一步。

推荐情绪：开心、好奇、惊讶、思考、害羞、发呆、委屈、打气、陪伴。避免过度颜艺、低俗表情、恐怖变形和大量复杂配饰。

## 联名共创

两个角色应共享一个画面语言，但必须分别可辨。保持各自的轮廓、面部身份和标志性符号；不得合并身体或交换身份特征。

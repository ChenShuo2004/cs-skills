# KAI 角色 DNA

`assets/reference-kai.png` 是 KAI 的唯一身份锚点。它是角色设定板，不是要直接贴进每张封面的模板。

## 不变量

- Q 版少年比例，圆润头身与粗黑描边；黑色、蓬松且有刘海的短发。
- 明亮钴蓝色反戴棒球帽，帽檐和帽带均可见；黑色边缘清楚。
- 暖白 / 浅灰白连帽衫，黑色裤装，蓝白运动鞋。
- 安静、克制、好奇的表情；可思考、阅读、工作或表达，不做夸张营销姿势。
- 主色：钴蓝 `#0059C0`、中蓝 `#3270D6`、暖白 `#F5EFF5`、近黑 `#111111`、浅蓝 `#8AC7F5`、橙色 `#FF8A1F`。

## 可变项

- 面向、镜头距离、站坐姿势、手势、表情强弱与主题物件。
- 主题物件只保留 1–2 个，如书、笔记本、便签、对话气泡或抽象思考线；它们应解释文章主题，不替代标题。

## 常见漂移与修复

| 发现 | 修复 |
| --- | --- |
| 帽子变成正戴、没有帽带 | 重申反戴蓝帽与可见帽带，优先保留帽子结构。 |
| 服装变成西装、彩色 T 恤或其他品牌 | 恢复暖白连帽衫、黑裤、蓝白鞋，移除额外品牌。 |
| 变成真人、成人插画或陌生卡通 | 回到 Q 版、粗黑描边、短发和固定服装锚点。 |
| 角色跑进左侧标题区 | 保持角色仅在右侧 40%，让背景保留干净暖白负空间。 |

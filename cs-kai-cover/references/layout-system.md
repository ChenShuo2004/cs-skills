# 5:2 标题优先版式

## 固定画布

- 成品：`2500×1000 px` PNG，5:2。
- 标题安全区：`x=140–1430`；角色安全区：`x=1500–2380`；四周不放关键信息。
- 标题使用近黑 `#111111`，放在覆盖左侧的暖白 `#F5EFF5` 半透明层上。蓝色只用于细横线或小圆点，橙色只用于一个小强调点。

## 层级

1. 最重要：原样中文标题，最大两行。
2. 可选：一行短副标题，低于标题一个层级。
3. 最小：左下角 `KAI` 标识；它不能抢标题或被误认为文章标题。
4. 右侧：KAI 与 1–2 个主题物件，不能越过标题安全区。

## 何时选姿态

| 文章信号 | 优先姿态 | 物件 |
| --- | --- | --- |
| 判断、认知、选择 | 托腮、凝视、指向 | 一条蓝色思考线或三张便签 |
| 产品、工作流、实操 | 坐在笔记本前 | 笔记本或任务卡 |
| 方法、学习、复盘 | 阅读或写笔记 | 书本、笔或小台灯 |
| 观点、表达、发布 | 轻微前倾、举手说明 | 对话气泡或一张纸 |

同一篇文章只选择一个姿态方向；不要把多种场景拼成一张信息图。

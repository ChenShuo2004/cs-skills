# 无标题背景提示模板

先替换方括号中的内容，并将 `assets/reference-kai.png` 作为身份参考传给图像工具。

```text
Create a clean 5:2 editorial cover background for a Chinese X / Twitter article.
Use the supplied KAI character reference as the only identity anchor: chibi boy,
fluffy black hair, a backwards cobalt-blue baseball cap with visible strap,
warm-white hoodie, black pants, blue-and-white sneakers, clean thick black outlines.
Place KAI only in the right 40 percent, in a [thinking / working / reading / explaining]
pose related to [article theme], with only [one or two simple props].
Keep the left 60 percent as spacious warm-white negative space with a subtle translucent
paper texture, one thin cobalt-blue structural line, and one tiny orange accent.
Modern, calm, intelligent, crisp editorial illustration; preserve the reference identity.
No text, no letters, no numbers, no logo, no watermark, no UI screenshot, no pseudo-text.
```

如果图像工具在衣服、背景或道具上生成了字符，即使不可读也视为失败；重新生成干净背景。最终 `KAI` 标识只由确定性排版层生成。

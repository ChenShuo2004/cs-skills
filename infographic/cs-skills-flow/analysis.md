## Main Topic

这张信息图解释 CS Skills 如何把模糊的 AI 创业目标，经由 `$cs-run` 路由到对应 skill，并覆盖从产品到交付的工作流。

## Learning Objectives

After viewing this infographic, the viewer should understand:
1. CS Skills 不是 Prompt 收藏夹，而是以目标驱动的任务系统。
2. `$cs-run` 位于目标与对应 skill 之间，负责启动工作流。
3. 11 个 active skill 覆盖产品、内容、调研、视觉视频与交付收尾。

## Target Audience

- **Knowledge Level**: Beginner to intermediate AI founders and independent developers
- **Context**: Reading a social-media post about an AI workflow skill library
- **Expectations**: Quickly understand what the library does and whether it fits their workflow

## Content Type Analysis

- **Data Structure**: 一个中心路由节点连接五类创业工作流，并以“目标 → 路由 → 验证结果”表现过程。
- **Key Relationships**: `$cs-run` 将模糊/跨域目标导向对应 skill；11 个 active skill 覆盖不同任务类型。
- **Visual Opportunities**: 中心人物头像、中心路由节点、五个模块化任务卡、清晰方向箭头、突出的“11”数字。

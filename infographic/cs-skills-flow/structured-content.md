# CS Skills：一个库覆盖 AI 创业全流程

## Overview

CS Skills 是一套以目标驱动的任务系统：从模糊/跨域目标出发，经由 `$cs-run` 进入对应 skill，推进到验证结果。

## Learning Objectives

The viewer will understand:
1. CS Skills 的核心工作流。
2. `$cs-run` 的入口位置。
3. 11 个 active skill 覆盖的创业任务范围。

---

## Section 1: Core Workflow

**Key Concept**: 目标驱动，而不是先选择 Prompt。

**Content**:
- 一句话说目标，让 Codex 自动选择工作流，把事情推进到可验证的结果。
- 模糊/跨域目标 → $cs-run → 对应 skill → 验证结果

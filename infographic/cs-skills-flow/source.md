# CS Skills：一个库覆盖 AI 创业全流程

一句话说目标，让 Codex 自动选择工作流，把事情推进到可验证的结果。

CS Skills 是陈硕在真实项目中沉淀的一组 Codex AI Agent 工作流。

它不是 Prompt 收藏夹，也不是一堆互相抢触发的 skill，而是一套精简的任务系统：

模糊/跨域目标 → $cs-run → 对应 skill → 验证结果

当前包含 11 个 active skill，覆盖产品设计、工程开发、内容创作、文章配图、深度调研、短视频策划/制作和交付收尾。

产品与工程：产品设计、前端实现、PRD 执行、代码清理、版本 checkpoint、验证、提交与部署收尾。

内容、调研、视觉与视频：文章、改稿、项目复盘、深度调研、竞品分析、小黄中文正文配图、电商短视频分镜与生成包、ChatCut 视频制作前的内容策划。

你不用先研究“到底该用哪个 Prompt”。直接说目标。

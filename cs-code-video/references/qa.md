# 自评验收

## 一键出检查素材

```bash
python3 scripts/qa.py out/final.mp4 qa            # 抽帧总览、手机尺寸抽帧、切镜点连续帧、波形与响度、追加一轮打分表
python3 scripts/qa.py out/final.mp4 qa --strips 4.1,12.5   # 指定时间点看连续 12 帧
```

然后 Read `qa/sheet.png`、`qa/sheet-phone.png`、`qa/strip-*.png`、`qa/audio_wave.png`，在 `qa/review_log.md` 里填分（qa.py 生成的表里没有「辨识度」这一行就手动补上）。

## 打分（每项 1–10，全部 ≥8 才能交付）

站在严格的动效导演视角挑毛病，别替自己说好话。

| 项 | 看什么 |
|---|---|
| 开场 | 前 2 秒有没有抓人的画面 |
| 手机可读 | 缩到 360 宽，字还看不看得清 |
| 动作 | 有没有匀速滑动、什么都不动的空拍 |
| 变化 | 每 2–4 秒有没有新东西出现 |
| 构图 | 主体够不够大，有没有空一大块或挤成一团 |
| 贴合 | 配色、字体、事实和 brief 一致 |
| 声画同步 | 重拍、音效、字幕是不是落在动作上 |
| 辨识度 | 关掉声音只看抽帧，能不能看出在讲什么（隐喻同构）；和 style-log 最近 3 支比像不像（单片不能像）；签名层元素是否都出现（signature.md 定稿后） |

列出最严重的 3 个问题和时间点。重点找：切换时新旧文字叠在一起、居中大字加渐变背景的默认画面、沿用了模板配色、角落里多余的标签和边框、缩放后变糊的字、循环接缝处的卡顿。

改完只重渲有问题的那几秒（`render.mjs --start --duration`），再跑一次 `qa.py`（自动记为下一轮），直到每项 ≥8。一般两三轮。

## 验收清单

- [ ] 时长、画幅、帧率和 brief 一致，有声音轨（除非 brief 写明无声）
- [ ] 抽帧里没有空白帧、没有残留到下一个镜头的元素
- [ ] 文字都在安全区内，没有溢出或被遮挡
- [ ] 同一个角色或元素在每个镜头里长得一样
- [ ] 事实类内容和原材料一致，不确定的已单独列给用户
- [ ] 响度约 -14 LUFS，真峰值 ≤ -1 dBTP
- [ ] 循环视频：连播两遍看接缝（`ffmpeg -stream_loop 1 -i out/final.mp4 -c copy qa/loop.mp4`）
- [ ] `style-log.md` 已追加这支片

# 导演层：先想画面，再选风格，最后选引擎

渲染管线（render(t)、配音、混音、QA）是固定的，**画面语言不固定**。以前的问题是先拿模板、再塞内容，结果每支片长得一样。导演层把顺序倒过来：

```
选题 → ① 系列还是单片 → ② 核心冲突 → ③ 隐喻发散 A/B/C → ④ 配风格 → ④+ 套 KAI 签名层 → ⑤ 风格卡 → ⑥ 选引擎
```

整个导演层只产出文字（风格卡），不写代码；用户选定后才渲一张关键帧。

**两层结构**：可变层（隐喻、材质风格、镜头）每支片按选题重新设计；不变层（KAI 签名层，见 [signature.md](signature.md)）每支片都带。风格库里的风格是别人的语言，套上签名层才是陈硕的片子。

## ① 系列还是单片（开工先问一句）

> 这支是某个系列的续集（沿用风格），还是独立单片（按选题重新设计画面）？

| 回答 | 怎么做 |
|---|---|
| 系列续集 | 锁住系列的「皮肤」（配色、字体、字幕、质感、片头片尾），**只放开隐喻和镜头**。直接走 ③，跳过 ④，风格卡只出隐喻差异 |
| 独立单片 | 全部放开，走完 ①–⑥ |
| 用户没回 / 无人值守 | 选题明显属于已有系列（见下表「适合」列）就按系列；否则按单片，并在风格卡里写明 |

### 已有系列皮肤

| 系列 | 引擎 | 锁住的东西 | 适合 |
|---|---|---|---|
| 像素解说 | `cs-pixel-explainer` | 像素画、坐标系隐喻、打字机字幕、edge-tts 配音 | 人际、心理、生活哲学类口播文案 |
| 暗夜知识片 | `cs-knowledge-film` | 暗夜星空、金/冰蓝/绯红语义色、宋体气质、钩子→章节→收束 | AI 原理、科学经典、认知偏差连续剧 |
| **KAI 教程片** | `cs-code-video` + [tutorial.md](tutorial.md) | GPT 插画镜头 + 深色网格讲解镜头、KAI 头像对口型、蓝橙配色、钩子→步骤→结果→签名收尾 | **所有教程类视频（默认）**：工具上手、工作流、AI 实测、Skill 介绍 |

新系列：某支单片效果好、用户说「以后这类都这么做」，就把它的风格卡存进本表。

## ② 核心冲突（一句话）

写下这支片要让观众看完记住的那**一个变化**：从什么状态到什么状态。

- 复利：一直看不到结果 → 突然爆满
- 幸存者偏差：看到的全是成功 → 原来大部分掉在画面外
- AI 幻觉：答案看起来对 → 其实是编的

冲突写不出来，说明选题还没想清楚，先回去和用户确认文案，不要急着想画面。

## ③ 隐喻发散：A 稳妥 / B 跨界 / C 疯狂

每个方向都要回答「用什么**看得见的动作**讲这个变化」，动作的结构要和概念的结构一样（同构）。

| 方向 | 要求 | 例：复利 |
|---|---|---|
| A 稳妥 | 最常见、一眼看懂 | 一条曲线前面贴地，最后冲出画面 |
| B 跨界 | 借一个不相干的领域：厨房、地铁、天气、生物、建筑、游戏、体育 | 面团发酵：前 9 小时看不出变化，第 10 小时顶开锅盖 |
| C 疯狂 | 物理上不可能但很好记：时间倒流、世界折叠、文字会生长 | 一个字每秒复制自己，最后整屏的字拼成一张脸 |

三项各打 1–5 分：**一眼看懂 / 同构 / 代码画得出**。总分最高的推荐给用户；平分优先 B。C 方向允许分低，它的作用是把思路撑开。

动作菜单（整片至少用 3 种，相邻镜头不重复）：切分、增长、筛选、对比、缩放、网络、时间、分叉、平衡、剖面、寻路、扰动、堆叠、坍缩。

## ④ 配风格：从隐喻长出来，不从模板长出来

先问三个问题，再查风格库：

1. 这个隐喻发生在什么**材质**里？（纸、屏幕、星空、厨房、地图……）
2. 这个选题的**情绪**是什么？（紧张、温暖、荒诞、冷静、怀旧）
3. 观众在**哪个平台**、用多大屏幕看？（竖屏手机要大字少元素）

### 风格库

| 风格 | 画面语言 | 适合 | 代码路线 | 字幕方式 |
|---|---|---|---|---|
| 手绘白板 | 白底黑线、马克笔高亮、手抖线条 | 商业概念、流程、方法论 | Canvas 2D + 抖动种子 `floor(t*12)` | 手写体跟着笔画出现 |
| 报纸拼贴 | 纸张纹理、剪报、胶带、红笔圈注 | 社会现象、历史、反转观点 | HTML/CSS + SVG 滤镜 | 剪报标题、打字机色带 |
| 等距 3D 小世界 | 小城市、小房间、俯视 45° | 系统、组织、流程、经济 | Three.js 正交相机 | 浮在物体上的标签 |
| 终端 / 代码界面 | 黑底等宽字、光标、日志滚动 | AI、编程、自动化、黑客感选题 | HTML 等宽排版 | 就是终端输出本身 |
| 数据可视化 | 干净坐标轴、柱、线、点，一处强调色 | 有数字、有对比、有趋势 | SVG / Canvas | 数字本身当主角，字幕极简 |
| 极简大字排版 | 只有字，字在变形、挤压、拆开 | 金句、观点、情绪强的口播 | HTML/CSS + 弹簧 | 字幕 = 画面 |
| 胶片纪录 | 颗粒、暗角、慢推、暖色 | 个人故事、复盘、创业日志 | Canvas + WebGL 颗粒 | 底部小字、留白多 |
| 纸艺 / 剪纸 | 分层纸片、投影、视差 | 温暖、成长、教育类 | Canvas 分层 + 阴影 | 纸条标签 |
| 霓虹 / 赛博 | 暗底、发光线、故障 | 科技、未来、速度 | Canvas + 光晕着色器 | 故障出字 |
| 蓝图 / 工程图 | 蓝底白线、尺寸标注、剖面 | 拆解产品、讲原理、讲结构 | SVG 描线动画 | 标注线引出说明 |
| 像素复古 | 小画布放大、限定调色板、CRT | 游戏感、怀旧、轻松 | Canvas + `crt.js` | 打字机 |
| 暗夜星空 | 星空、发光点、语义色 | 宇宙感、科学经典 | 走 `cs-knowledge-film` | 宋体、慢出 |
| 插画解说（GPT × 代码） | GPT 手绘插画镜头 + 深色网格讲解镜头交替，KAI 头像对口型 | 教程、工作流、工具实测、复盘 | GPT 出图 + `layers.js`，见 hybrid.md | 插画用字幕条，讲解用白字 |

风格库不是上限：隐喻需要的材质表里没有，就直接设计一个新风格，写清画面语言、配色、字体、字幕方式。

### 防撞车

开工前读 `style-log.md`（最近做过的片子和风格）。**单片**不能和最近 3 支用同一种风格；系列续集不受限。做完把这支追加进日志。

### 配色与字体

每支片单独定：1 个底色、1 个主色、最多 1 个强调色；字体从风格出发（手绘用手写体、报纸用衬线、终端用等宽）。不要默认深色底加黄色字。

## ④+ 套 KAI 签名层

读 [signature.md](signature.md)，把「不变层」逐条落到这支片的风格上：信号色怎么用、签名动作在哪个镜头发生、片头片尾、字幕、声音标识。风格和签名冲突时（比如霓虹风和纸张质感），保留签名的**结构性元素**（签名动作、叙事结构、片头片尾、信号色），质感可以让给风格。

签名层还没定稿时（signature.md 状态为「待定」），跳过这一步，并在风格卡里注明。

## ⑤ 风格卡（给用户看的就是这个）

三张卡，每张不超过 9 行：

```
【A 稳妥｜曲线冲出画面】      一眼看懂 5 · 同构 4 · 画得出 5 = 14
核心画面：一条贴地的线，最后 3 秒突然冲出屏幕顶端
风格：数据可视化 · 米白底 + 墨黑线 + 一处橙色
开场 2 秒：屏幕上只有一个「1%」，被轻轻推了一下
动作：增长 → 对比 → 缩放
字幕：数字当主角，口播字幕小字在下方
声音：钢琴单音逐渐加密
签名：签名动作落在第 3 镜（曲线冲出画面那一刻）
风险：最常见，不够意外
```

在卡片下面写推荐哪张和一句理由，然后等用户选（可以混搭）。**只给选中的方案渲一张关键帧**，确认后再写 brief。

## ⑥ 选引擎

| 情况 | 走哪里 |
|---|---|
| 系列续集：像素解说 | `cs-pixel-explainer` |
| 系列续集：暗夜知识片 | `cs-knowledge-film` |
| 教程类视频 / 系列续集：KAI 教程片 | `cs-code-video`，按 [tutorial.md](tutorial.md) 走，跳过风格卡 |
| 单片，或风格库其他风格 | `cs-code-video`，`assets/template.html` 只用骨架（render(t)、弹簧、时间表），`STYLE` 和所有镜头按风格卡重写 |
| 单片但选中像素复古或暗夜星空 | 可以借用那两个引擎，但配色、字幕、隐喻按风格卡改，不照搬系列皮肤 |

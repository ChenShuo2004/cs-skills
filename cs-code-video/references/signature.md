# KAI 签名层（陈硕个人风格体系）

> 状态：**待定**。候选方向见下文第三节，陈硕选定并用样张验证后，把选中的方向填进第一节，状态改为「v0.1」。

## 一、不变层（每支片都带，定稿后填写）

只锁 8 样东西。锁得太多就变回模板，锁得太少观众认不出来。

| # | 元素 | 定稿内容 |
|---|---|---|
| 1 | 信号色 | 一个颜色，全片只用在「关键变化」上 |
| 2 | 底色与质感 | 默认底色 + 一种质感（可被风格覆盖） |
| 3 | 字体 | 标题一种、正文一种、批注一种 |
| 4 | 签名动作 | 每支片必须出现一次的那个动作 |
| 5 | 叙事结构 | 每支片的骨架 |
| 6 | 片头 / 片尾 | 前 1 秒的识别标志 + 结尾定版 |
| 7 | 声音标识 | 签名动作和片尾时的固定音效 |
| 8 | 角色 | 主角 KAI 男孩 + 宠物 KAI 猫，每支片都出场（设定见第五节） |

## 二、吸收清单：从别人那里拿什么

参考视频只拿**手法**，不拿外观。每吸收一个新参考，在这里加一行，写清拿走了什么、放弃了什么。

| 来源 | 拿走的手法 | 不拿的东西 |
|---|---|---|
| 像素解说（注意力赌博） | 用坐标系把抽象关系画成位置；打字机出字的节奏感 | 像素画外观、CRT |
| Vibe 知识大赏（暗夜知识片） | 语义色（颜色有固定含义）；动作和概念同构；钩子用观众能参与的小实验 | 星空背景、宋体气质 |
| xilo 代码视频 | 一个形状贯穿全片不断变形、不切镜；闭式弹簧；动作卡节拍 | 界面发光、默认深色居中大字 |
| Dan Koe 视觉 | 黑白高对比、纸张纹理、强标题、少元素 | 励志导师的语气 |

## 三、候选方向（选一个作为底，可以混）

三个方向都从陈硕自己的东西长出来：账号定位是「公开工作台 + 创业日志 + 实验室」，内容结构是「我用了 → 我测试了 → 我做出了东西 → 告诉你结果」，视觉偏好是黑白、高对比、纸张、少元素。

### A｜实验笔记 Lab Notes（推荐作为底）

- 画面：米白网格纸 + 墨黑线，一个信号色（候选：荧光橙）
- 签名动作：**草稿 → 成品**。每个概念先以潦草铅笔线出现，在关键时刻被一道扫描线「Build」成干净的图形，信号色在这一刻第一次出现
- 叙事结构：假设 → 实验 → 结果 → 复盘（就是他写复盘的结构）
- 片头：右上角实验编号 `EXP-017` + 日期，像笔记页眉
- 片尾：版本号 `v0.1 → v1.0` 定版，配一句「下一个实验」
- 声音：铅笔沙沙声底；Build 时一声短促的「咔哒」
- 为什么是他的：把「不断把想法做出来，并公开记录」直接变成画面动作，别人借不走
- 风险：画面偏安静，抖音前 2 秒冲击力要靠钩子补

### B｜黑白信号 Signal

- 画面：纯黑底 + 白色大字 + 纸张颗粒，一个信号色
- 签名动作：一个小方块（光标）贯穿全片，不断变形成每个概念的形状
- 叙事结构：一句反常识钩子 → 证据 → 判断 → 行动
- 片头：黑屏中光标闪两下，变成标题
- 为什么是他的：和他的封面审美（Dan Koe 式黑白强标题）一脉相承，X 和封面能统一
- 风险：黑底大字是很多人的默认风格，签名动作做不好就会像模板

### C｜工作台俯拍 Desk

- 画面：等距俯视一张工作台，概念都是桌上被组装的物件，KAI 猫在桌上动手组装
- 签名动作：零件被拼装成一个完整物件
- 叙事结构：拆开 → 组装 → 运行 → 结果
- 为什么是他的：最像「公开工作台」，KAI 猫的戏份最足
- 风险：Three.js 制作成本最高，每支片都要新建模型，日更不现实

### 推荐组合

**A 做底，借 B 的开场**：前 2 秒用黑底信号色大字做钩子（抖音需要冲击力），然后「翻开笔记本」进入 A 的实验笔记画面。C 留给重要的年度片或产品发布片。

## 四、定稿前的验证（不要直接写死）

1. 选一个已有选题（建议「复利」或「幸存者偏差」），按选中方向渲 3 张样张：开场帧、签名动作帧、片尾定版帧。
2. 同一选题再换一种风格库风格 + 签名层渲 1 张，看签名层套到别的风格上还认不认得出来。**这是检验体系是否成立的关键**：换了材质还能认出是 KAI 的片子，才算风格体系。
3. 陈硕确认后填第一节，状态改为 v0.1。做满 5 支片后复盘一次：哪些元素观众真的记住了（评论、完播），没用的删掉。

## 五、角色体系 v0.1：主角 KAI + 宠物 KAI 猫

| | 主角 · KAI 男孩 | 宠物 · KAI 猫 |
|---|---|---|
| 是谁 | 陈硕本人的化身：Small boy, big ideas | KAI 的 AI 搭档 |
| 性格 | 简单、善良、好奇，默认表情是「淡定」的半睁眼 | 活泼，闪电眼一亮就开干 |
| 戏份 | 提出问题、有想法、做实验、做判断 | 帮忙、反应、在关键时刻放闪电把想法 Build 出来 |
| 3D 代码 | `assets/kai-boy-3d.js` | `assets/kai-cat-3d.js` |
| 原设定图 | `assets/character/kai-boy-sheet.png` | `assets/character/kai-cat-*.png` |

**两个人的分工就是你的内容主线：人有想法，AI 帮他做出来。** 签名动作由两人一起完成：KAI 举手说「做！」→ 猫的闪电劈下来 → 草稿变成品。

### 品牌色（以男孩为准）

|---|---|---|
| KAI 蓝 | `#0059C0` | 主色：标题、帽子、Logo |

| 卫衣白 | `#F5EFF5` | 浅色底 |
| 黑 | `#111111` | 文字、深色底 |

猫的耳机黄、闪电红只是猫自己的识别点，不进全局配色。

### KAI 男孩：识别点

1. 反戴的蓝色棒球帽（前面露出调节带）
2. 乱乱的黑发 + 淡定的半睁眼 + 脸颊三个浅蓝点
3. 白色卫衣，胸前蓝色「KAi」+ 橙色 i 点和小三角；黑裤子，白鞋蓝底

### KAI 男孩：3D 版用法

```js
const kai = KaiBoy3D(1080, 1080);
kai.render({ t, yaw, mode: 'color', pose: 'pocket', pose2: 'wave', poseMix: k, expr: 'calm', bg: 'transparent' });
// pose : pocket 手插口袋 | wave 挥手 | build 双手向前 | point 指向
// expr : calm 淡定 | happy 开心 | wow 惊讶 | think 思考 | sleepy 发呆
```

和猫同框：两个都用 `bg: 'transparent'` 渲染，猫按男孩身高的 0.45–0.5 缩放，放在他脚边。

已知差距：头发是几大撮，不如原图碎；帽子正面的调节带比较简化；没有黑描边（3D 软陶质感取代了原图的线稿感）。

## 六、KAI 猫（宠物）细节


原图：`assets/character/kai-turnaround.png`（三视图）、`assets/character/kai-pose.png`（透明底举爪）。代码版：`assets/kai-cat.js`。设定卡：`assets/character/kai-sheet.png`、跨风格验证：`assets/character/kai-styles.png`。

### 外形

- 炭灰色绒毛小猫，大头小身（头连耳机约占全高 60%），圆耳朵内侧奶白色，尾巴向上卷
- 黄色头戴耳机：头梁顶部有深灰软垫，两侧耳罩上各有一个白色闪电
- 大眼睛，白底**红色闪电瞳孔**，左上一个高光点；短眉毛，猫嘴「ω」，粉色腮红
- 胸前蓝色立体字 **KAI**

### 猫的识别色（只属于猫）

| 名称 | 色值 | 用在哪 |
|---|---|---|
| 炭灰 | `#55555A` | 角色主体；也适合当深色底 |
| 耳机黄 | `#FCC23C` | 猫的耳机、闪电 |
| 闪电红 | `#E5262B` | 错误、警告、反转 |
| KAI 蓝 | `#2F80F5` | 名字、链接、正确答案 |

### 识别点（任何风格都不能丢）

1. 黄色耳机 + 白闪电
2. 红色闪电瞳孔
3. 胸前蓝色 KAI

像素、线稿、黑白剪影里只要这三样在，就能认出是 KAI 猫（已在跨风格验证图里测过）。

### 戏份

- 跟在 KAI 身边的搭档：KAI 想、KAI 做实验，猫负责递工具、做反应，在 Build 那一刻放闪电
- 不抢戏：每支片出场 2–4 次，每次 1–2 秒
- 闪电是猫身上天然的母题（眼睛和耳机上都有），是签名动作的视觉：闪电劈下来，草稿变成品，信号橙第一次出现

### 3D 版（主力）：`assets/kai-cat-3d.js`

用 WebGL2 光线步进（SDF）实时渲染，零依赖，浏览器里直接跑，符合「画面只由 t 决定」。

- 制作顺序：**先白模定比例**（`mode: 'clay'`，对照原版三视图调头身比、耳朵、耳机、尾巴），**再上材质**（`mode: 'color'`：绒毛 sheen、塑料耳机高光、闪电眼、立体 KAI 字）
- 用法：
  ```js
  const cat = KaiCat3D(1080, 1080);
  cat.render({ t, yaw, mode: 'color', pose: 'stand', pose2: 'build', poseMix: k, expr: 'focus', bg: 'transparent' });
  ctx.drawImage(cat.canvas, 0, 0);   // 透明底，可以叠进任何风格的画面
  ```
- 姿势：stand / build / wave / point，用 `pose2 + poseMix` 平滑过渡；表情：smile / happy / focus；眨眼、呼吸、摆尾、头部轻摆自动
- 渲染速度（云端无 GPU）：1080×1080 约 10–20 秒一帧；本地有显卡的电脑上接近实时。长片先用 540 分辨率出小样
- 已知差距：眼睛比原版圆、耳机耳罩少一圈台阶细节、绒毛没有毛发颗粒。特写和封面仍用原版 3D 图

### 两个版本怎么选

| 场景 | 用哪个 |
|---|---|
| 日常出镜、转身、做动作（默认） | 3D 版 `kai-cat-3d.js` |
| 要换成扁平 / 线稿 / 像素画风 | 2D 版 `kai-cat.js` |
| 封面、片头定版、特写镜头 | 原版 3D PNG |
| 需要 3D 跑跳等复杂动作 | 用原图做参考，视频模型出绿幕片段再叠加（见 code-stack.md） |

### 代码版用法

```js
drawKaiCat(g, { x, y, size, t, pose, expr, style })
// pose : stand 站立 | build 举爪 | wave 挥手 | point 指向
// expr : smile 微笑 | happy 开心 | wow 惊讶 | think 思考 | focus 专注（闪电眼发光）
// style: flat 扁平 | line 手绘线稿 | pixel 像素 | mono 黑白 + 信号色
drawBolt(g, cx, cy, h, color)   // 单独画一个 KAI 闪电
```

眨眼、呼吸、摆尾、抖耳朵、线稿抖动全部由 t 算出，符合「画面只由 t 决定」。

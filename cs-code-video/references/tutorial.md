# KAI 教程片（系列）

**叫法**：「做一支 KAI 教程片：主题 ×××」，或 `$cs-kai-tutorial ×××`（个人技能卡里叫 `kai-tutorial`）。
**适用**：所有教程类视频：工具上手、工作流演示、AI 实测、Skill 介绍、「从零做出 ×××」。
**来源**：拆解 xilo《用 Claude 做 AI 梦核短片》后，换成陈硕自己的角色、配色和签名动作。方法细节见 [hybrid.md](hybrid.md)。

这是一个**系列皮肤**：画风、版式、角色、字幕全部锁住，每支片只换内容和插画。做教程时默认就走它，不再出三张风格卡。

## 一、锁住的东西

| 项 | 规定 |
|---|---|
| 镜头 | A 插画镜头（GPT 图 + 运镜）约 35%；B 讲解镜头（深色网格 + 代码界面）约 60%；C 角色镜头（签名动作）1–2 次 |
| 节奏 | 一个镜头 2–4 秒，平均 3 秒一切；插画镜头不超过 4 秒 |
| 主角 | KAI 男孩：插画镜头里满幅出镜做事；讲解镜头左下角圆形头像，三种嘴型对口播 |
| 宠物 | KAI 猫（AI 搭档）：插画镜头里和 KAI 一起干活；讲解镜头右下角黄圈头像，AI 干活时接话；Build 那一刻放闪电。详见第二节 |
| 配色 | 讲解镜头：深色网格底 + 白字 + 信号橙 `#FF8A1F` 只标重点；插画镜头：暖白底 + 圆角画框 |
| 字幕 | 插画镜头黑底白字字幕条；讲解镜头白字无底 |
| 界面组件 | `layers.js`：`promptBox` 对话框、`card` 素材卡、`bigStep` 步骤大数字、`avatar` 头像 |
| 插画 | 统一用 hybrid.md 的 KAI 风格提示词 + 角色设定图做参考；图里不放字 |
| 画幅 | 横版 1920×1080 为主；要发抖音、视频号时另出 1080×1920，不直接裁 |

## 二、KAI 猫在片子里做什么

分工就是你的内容主线：**KAI 是人，负责想和判断；KAI 猫是 AI，负责干活。** 教程里凡是「AI 在做事」的地方，都交给猫来演。

| 场合 | KAI 猫怎么出现 |
|---|---|
| 插画镜头 | 陪在 KAI 旁边做 AI 的活：抱着一摞图跑过来、对着屏幕放小闪电、把胶片递给 KAI。每 3–4 张插画至少一张有猫 |
| 讲解镜头 | 右下角黄色圆圈头像（左下是 KAI）。KAI 打出提示词 → 发送 → 猫的头像亮起、说话线动起来，同时结果卡片弹出来 |
| 等待 / 生成中 | 猫的头像耳机闪电一闪一闪，代替进度条 |
| 出错 / 不满意 | 猫做「无辜」表情，KAI 改一句提示词，再来一次 |
| 签名收尾 | KAI 举手说「做！」→ 猫的闪电劈下来 → 成品出现 |

规则：

- 两个头像不同时说话：KAI 说话时猫闭嘴，反过来也一样
- 猫只做反应和干活，不抢口播；口播永远是 KAI（陈硕）的声音
- 猫的颜色（耳机黄、闪电红）只用在猫身上，不拿来做全局强调色

## 三、固定结构

```
① 钩子（5–10s）    先给结果：做出来的东西 / 惊人的数字 / 前后对比。插画或成品画面
② 预告（5s）       「今天分 N 步」：bigStep 一排数字依次亮起
③ 步骤 × N         每一步：bigStep 标题 → 1 个插画镜头讲「为什么」→ 2–4 个讲解镜头讲「怎么做」
                   KAI 用 promptBox 打出真实提示词 → 猫头像亮起接活 → 结果用 card 摆出来，选中的那张亮起来
④ 结果和成本（10s） 成品 + 花了多少时间 / 积分 / 钱，数字用代码打出来
⑤ 签名收尾（5s）    KAI 举手说「做！」→ 猫放闪电 → 一句总结 + 关注 / 收藏引导
```

一支 2–4 分钟：40–80 个镜头，插画 10–20 张。

## 四、每支片要准备的

1. **口播稿**：按结构写，每句 8–25 字。事实、价格、步骤必须来自陈硕给的原材料或亲测记录，不确定的标出来
2. **分镜表**：每个镜头写 类型 / 时长 / 画面 / 用哪张图 / 字幕（写进 brief.md 的 structure）
3. **assets.json**：所有插画 + 两条头像（KAI 三种嘴型、KAI 猫三种状态：平常 / 闪电眼发光 / 开心），头像整个系列共用，第一次出好以后复用
4. **真实素材**：教程里要展示的截图、生成结果、录屏片段，陈硕提供，放进 `source/`

## 五、制作步骤

1. 问一句：主题、时长、横版还是竖版、有没有配音
2. 写口播稿 + 分镜表，给陈硕确认
3. 整理 assets.json → `gen_image.py --dry-run` 给他看张数 → 出草稿 → 挑图 → 定稿
4. 配音（edge-tts 或陈硕自己录）→ `audio.py vo` 生成时间轴，镜头按口播对齐
5. 用 `template.html` 骨架 + `layers.js` 逐镜头做；每 10 个镜头渲一次小样检查节奏
6. 混音、渲染、`qa.py` 自评，追加 style-log

## 六、验收（在 qa.md 八项之外）

- [ ] 前 5 秒出现结果或钩子，不是自我介绍
- [ ] 每一步都有「为什么」的插画镜头和「怎么做」的讲解镜头
- [ ] 插画里没有乱码文字；所有文字都是代码叠的
- [ ] KAI 在插画里每张都长一样；头像嘴型只在说话时动
- [ ] 没有连续超过 4 秒不动的画面
- [ ] KAI 猫至少在 1/4 的插画里出现；讲解镜头里 AI 干活的地方都是猫在接话
- [ ] 两个头像没有同时说话
- [ ] 结尾有签名动作

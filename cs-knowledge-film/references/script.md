# 口播稿写法

## 先选画面隐喻

写稿前先回答：观众原来怎么理解、看完要改变什么理解、哪一个可见的变化最能说明这个转折。每章至少考虑两种不同画面，再选最清楚的一种；不要为了使用现成场景而改写论点。

## 可选骨架

```text
00 序    钩子：让观众亲自做一次小实验（猜下一个字 / 猜一个数 / 读一句乱序的话）
         → 立刻给出反差 → 一句话点题
标题     片名 + 四字副题 + 英文 kicker
01–04   每章：一个问题 → 一个画面隐喻 → 一个数字或史实 → 一句收束
尾声     回到序章的实验，换成开放式：“这一次，由你来填。”
```

这个骨架适合有体验式实验的主题。若主题更适合人物、对比或推理过程，就按其因果顺序组织；不要沿用参考片的章节名称和隐喻。

## 句子

- 8–25 字一句，一句一个意思；长句拆开，用 `pause` 留气口。
- 口语，第二人称“你”；少用“我们”；不用“众所周知”“让我们一起”。
- 每章至少一个具体的数：`p = 1/365 → 8.5 bits`、`20 瓦`、`1948 年`。数字必须能查证。
- 结论句放章末，用金色标出关键词。
- 英文字幕是意译，不是逐字翻译；保持短。

## 时长估算

- 中文口播约 4 字/秒（edge-tts `-6%` 语速）。
- 2 分钟 ≈ 450 字 ≈ 30 句 ≈ 10–12 个场景。
- 标题场景无口播，`minDur: 5.5`。

## 自检

- 删掉画面只听口播，能听懂吗？
- 只看画面不听口播，能看出每章在讲什么吗？
- 结尾那句话，观众会不会想转发？

# 验收清单

## 渲染前

- [ ] 需要口播时，先重跑 `tts.py` 和 `timeline.mjs`，确认输出“配音: 有”；纯字幕版确认 `readSpeed` 与实际阅读节奏相符。
- [ ] 打开 `preview.jpg` 逐格看：每个场景都有主体、没有“未知场景类型”“缺少图片”红字。
- [ ] 对关键事件用 `--still <秒>` 抽帧：数字揭晓、灯亮、遮罩、头条。秒数从 `timeline.json` 的 `lines[].start` 查。

## 画面

- [ ] 主体不进入底部 20% 字幕区。
- [ ] 长句（>22 字）在字幕里不出画；主字（typewriter / textplay）不超过画面宽 85%。
- [ ] 一屏最多一处金色重点；红色只出现在噪声 / 错误 / 头条。
- [ ] 标题碰撞不过曝成灰屏。
- [ ] 数轴刻度缩放时没有数字重叠。

## 声音

- [ ] 配音与字幕同步（事件锚在 `L#` 上）。
- [ ] 使用程序配乐时跑过 `score.py`：音效落在画面事件上（标题撞击、选中、灯亮），不是只有一层铺底。
- [ ] 成片响度约 -16 LUFS、真峰值 ≤ -1.5 dBTP（`ffmpeg -af loudnorm=print_format=summary`）。
- [ ] 有口播时配乐让位：`"musicVolume": 0.6`；用自己的 BGM 时 `"music": false`。
- [ ] 结尾有 ≥1.5s 静默余韵（`hold`）。

## 交付

- [ ] `ffprobe video.mp4`：1920×1080、时长与 timeline.total 一致；需要声音的版本还应有音轨。
- [ ] 附上 `subtitles.srt` 和 spec 里使用的图片来源。

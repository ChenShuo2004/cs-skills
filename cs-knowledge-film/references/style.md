# 视觉风格规范

参考：B 站 / YouTube「Vibe知识大赏 · 信息论：惊奇之学」（2560×1440，60fps，约 5 分钟）。以下是从原片逐帧拆出来的规则，引擎已默认实现，改动前先想清楚。

## 画面

| 元素 | 规则 | 引擎位置 |
| --- | --- | --- |
| 底色 | `#03050a`，中心一团很淡的藏蓝径向渐变 | `background()` |
| 星空 | 约 500 颗，缓慢横移 + 闪烁；标题 / 公式场景密度调高（`"stars": 0.9`） | `STARS` |
| 暗角 + 颗粒 | 边缘压暗 70%，颗粒 overlay 4.5% | `finish()` |
| 主字 | 中文衬线，68–120px，字距 10–46px，带极淡辉光 | `text()` |
| 数学 | 拉丁字母自动 Lora 斜体，中文保持正体（`math: true`） | `fontFor()` |
| 章节标签 | 左上 `01`（等宽金色）+ 汉字 + 英文大写字距 | `chapter()` |
| 字幕 | 中文 38px 居中于 86.5% 高度，英文斜体灰色在下 | `subtitles()` |

## 颜色语义（只用这几种）

| 名称 | 色值 | 意义 |
| --- | --- | --- |
| `gold` | `#f2c77c` | 重点、答案、惊奇、被点亮 |
| `amber` | `#e89a4a` | 火光、灯的外晕 |
| `ice` | `#a9dcff` | 数轴、结构、已知、冷静 |
| `cyan` | `#5cc9ee` | 信号、弧线、平静的波 |
| `red` | `#e2415d` | 噪声、错误、被排除、头条 |
| `dim` | `#8d939e` | 注释、英文、次要信息 |

文案里用 `[g]…[/g]` `[i]…[/i]` `[c]…[/c]` `[r]…[/r]` `[d]…[/d]` 给字上色。一屏最多一处金色重点。

## 动效

- 场景之间：前一场 0.5s 淡出到黑，后一场 0.6s 淡入；没有其他转场。
- 元素出现：透明度 + 轻微位移（≤16px），`easeOutCubic`，0.6–1s。
- 光点：白色内核 + 两层径向辉光；火光带不规则闪烁。
- 节奏：一句口播对应一个画面变化；变化发生在该句开头（`"L2"`）或句中（`"L2+0.6"`）。

## 什么会破坏风格

- 黑体、粗体、描边字、彩色渐变字。
- 同屏超过 2 个强调色；大面积高饱和色块（红色只用于小块遮罩和头条）。
- 快速运镜、缩放弹跳、闪白。
- 画面元素压到底部 20% 字幕区。

# 成片验收

1. 运行 `node scripts/validate-story.mjs story.json`；核对音频和角色哈希、FFprobe 时长、镜头连续性、章节覆盖与章首 B-roll。
2. 先渲染开头两章样片，查看章节卡、A-roll 左右站位、角色清晰度和 B-roll 是否以事件而非扩大面板讲故事。独立查看至少一张入场中途和落位后的帧。
3. 对每章抽一张 A-roll、一张 B-roll 和转场卡；检查场景关键词、动作和后期字幕区域。对 3:4、4:3 封面各检查原图和缩至约四分之一的缩略图。
4. 用 FFprobe 核对成片宽高、30fps、H.264/AAC、视频帧数和音频时长；用 FFmpeg 完整解码。视频可能因帧和 AAC 对齐比源音频长不足一帧或一个音频包，记录实际差值，不用时间拉伸消除。
5. 核对输出确实使用锁定的原声。最后一句要实听；工具环境不能听音时只可报告 ASR 与波形/时长检查，不得写“人耳听审通过”。
6. `phrase-timeline.json` 若存在，核对 `schema_version: 2`、`estimated_fallback_used: false`、真实 `timing_source` 与音频来源一致。仅有自动转写且未经校对时，不能把 SRT 标记为准确可发布字幕。

QA 报告应包含输入素材哈希、命令与结果、抽帧位置、封面尺寸、未完成的人耳或文稿校对项。静态代码通过、渲染成功和内容听审分别记录，互不替代。

## 基础轮廓

主体是一个不规则、微倾斜的暖黄色软团，也可以称为“温度种子”。

必须保留：

- 接近偏椭圆种子与柔软水滴的结合，但不是标准梨形。
- 左下略鼓、右上略收。
- 重心微偏，轮廓不能过度对称。
- 身体看起来柔软、轻盈、有弹性。

提示词可使用：

```text
asymmetric warm seed blob, soft irregular silhouette, slightly leaning organic form
```

禁止：标准圆球、标准鸡蛋、普通水滴、梨子水果、动物身体。

## 顶部识别符号

顶部保留一根细长、略弯的“温度天线”。天线末端必须是暖橙黄色的空心爱心轮廓。

爱心通过细线从身体长出，不能直接贴在头顶。

禁止替换为：实心红心、两片叶子、花朵、王冠、火焰或普通触角球。

## 面部

- 两只黑色纵向椭圆眼睛。
- 眼睛间距偏宽。
- 极简小弧线嘴。
- 不画鼻子。
- 两侧淡橙色腮红可以减弱，但不要完全消失。

禁止改成大眼动漫、玻璃眼、迪士尼眼、复杂眉眼或写实五官。

## 四肢

- 手脚使用极细黑色线条。
- 末端高度简化。
- 默认不画人类手掌细节。
- 默认不加鞋子或手套。

禁止粗短卡通四肢和复杂关节。

## 连接爱心

标准形象的右侧手臂可以延伸或托起一个暖橙色空心爱心，与顶部爱心形成呼应。

它代表连接、传递和点亮。普通生活场景可移除；品牌说明、连接、陪伴、共创与传递主题优先保留。

## 颜色

| 用途 | 色值 | 说明 |
| --- | --- | --- |
| 主体基准 | `#F6B72A` | 暖金黄 / 蜂蜜黄 |
| 主体高光 | `#FFD86A` | 温和亮部 |
| 主体深部 | `#E99A1B` | 体积与手绘层次 |
| 辅助暖橙 | `#F59A23` | 爱心、连接线、少量强调 |
| 墨黑 | `#151515` | 五官和四肢 |
| 暖白背景 | `#FFF9EF` | 默认背景 |

保持“主体暖黄 + 黑色极简五官四肢 + 少量暖橙”。避免荧光黄、廉价渐变、赛博蓝和彩虹扩色。

## 品牌语义

“有温度”不只是可爱。它代表：

- 连接
- 陪伴
- 点亮
- 降低距离
- 让知识进入生活
- 让好的东西真正被人使用

画面优先表现角色正在连接、递出、点亮或陪伴，而不是静止卖萌。

## 身份优先级

当要求发生冲突时，按以下顺序决策：

1. 用户当前明确指令。
2. 已确认的角色身份锚点。
3. 当前任务的结构与语义。
4. 风格参考、媒介和装饰细节。

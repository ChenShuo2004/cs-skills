# QA Checklist

## 身份必过项

- [ ] 轮廓是不规则、微倾斜的温度种子，而不是标准梨子、鸡蛋、圆球或水滴。
- [ ] 左下略鼓、右上略收，轮廓没有过度对称。
- [ ] 顶部保留一根细长弯曲天线和一个暖橙色空心爱心。
- [ ] 保留间距偏宽的黑色纵向椭圆眼、小弧线嘴和淡橙腮红。
- [ ] 没有鼻子、动漫大眼、玻璃眼或复杂眉眼。
- [ ] 四肢足够细，末端简化，没有默认鞋子、手套和人类手掌。
- [ ] 主体为暖黄，五官四肢为墨黑，只使用少量暖橙强调。

## 任务必过项

- [ ] 用户要求的动作、场景、媒介或风格已经完成。
- [ ] 角色正在执行有意义的核心动作，不是只站着卖萌。
- [ ] 风格迁移只迁移视觉语言，没有复制参考角色的身份元素。
- [ ] 联名角色保持各自身份，没有合并轮廓或交换标志物。
- [ ] 一张图只有一个核心任务，背景和装饰没有抢角色。
- [ ] 没有多余文字、Logo、水印或未要求的角色与道具。

## 失败信号

出现以下任一问题时，优先重新生成或做单一目标编辑：

- 顶部爱心变成实心红心、叶子、花朵、火焰或触角球。
- 身体出现果梗、叶片等梨子水果细节。
- 四肢变粗、出现鞋子手套或人类手掌。
- 面部变成通用可爱吉祥物、动漫角色或写实五官。
- 主体变成毛绒、针织、长毛、金属或过度玻璃化。
- 颜色扩成彩虹、荧光黄、廉价发光或赛博蓝。
- 风格迁移后无法一眼认出“有温度”。

## 迭代规则

- 只有一个局部失败：固定全部不变量，只编辑失败部位。
- 两个及以上身份锚点失败：重新设计，不继续微调。
- 多版本结构雷同：改轮廓比例、重心、凹凸与肢体位置，不只换材质。
- 画面只剩“可爱”：增加连接、传递、点亮或陪伴动作。

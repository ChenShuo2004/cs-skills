# 自媒体剧本：内容承诺、因果与可拍表达

从素材写剧本、修复推进或去模板感时读取。已有稿件只补镜头和提示词时，不重新开发故事。

## 选择推进方式

| 形式 | 检查主线 | 材料依据 |
| --- | --- | --- |
| 观点口播 | 问题 → 依据 → 判断 → 适用边界 | 真实观察、案例、可核实外部来源 |
| 项目复盘 | 目标 → 尝试 → 阻力 → 调整 → 结果 | 原始项目过程、界面、版本与反馈 |
| 教程演示 | 用户任务 → 必要操作 → 输出 → 限制 | 实际输入、录屏和输出 |
| 情景短剧 | 人物目标 → 阻力 → 行动 → 后果 | 既定人物、场景与可表演动作 |

先提取受众、具体问题、内容承诺、可用证据和制作限制。材料足够时直接写；不以填完整表为前置条件。不把影视剧页码、幕数、倒计时、人物弧或反转强加给口播。

先确定材料能支持的结尾，再选开头的问题或具体瞬间。结尾可以是结果、重新判断、具体行动或真实尚未解决的问题；开头承诺要在正文得到回应。

## 推进检查

项目故事检查“因为发生什么，所以采取什么动作，结果促使怎样调整”。观点检查依据是否足以推出判断；教程检查操作是否帮助完成目标。一个事件接着另一个事件不自动构成因果。

每段检查：新增什么信息、证据、行动或判断；为什么此刻需要；删掉后损失什么。允许反应、停顿与铺垫，不要求每句话都承载新知识。没有新作用的同义句合并。

只有情景短剧需要角色争取、回避、试探等可表演目的；个人 IP 口播可以直接解释，但核心判断要有事实或过程支撑。生成配图只能说明概念，不能补造现实经历。

## 表达与审稿

- 将可朗读正文与镜头、表演、后期说明分开。
- 事实、作者观点、推测和待确认项分清；未知数据不填，计划不写成结果。
- 去模板感先定位重复因果、同义段落、过度解释、每段都总结或同构金句，再定点修改措辞。
- 不按禁词表抹掉作者口癖、自然停顿或有功能的重复。
- 目标时长先用明确语速假设估计；朗读和最终音频后再校准，不声称仅凭字数做了实听。
- 稿件变化会影响镜头、图片或后期文字时，回写对应条目，避免旧提示词继续引用旧台词。

问题说明使用具体位置、影响与修改理由，不给未经校准的爆款评分。完整文本交付不等于传播、表演或成片质量已验证。

# v0.7.0 本地安装与发布验收

目标：先统一并更新本地 CS Skills，再更新 GitHub 默认入口与完整安装包。以远端 main 为基底，保留既有能力，合入本地新增技能与模型检测。

## Skill 使用

按 cs-run 串联：cs-writer 负责 README 的产品介绍、表达与使用示例；cs-clean-code 核对目录、依赖、安装与验证；cs-github-push / cs-ending-time 负责限定范围的 GitHub 与安装包交付。

- 注册表：22 个任务技能与 1 个辅助技能；辅助项默认不安装，本机已按用户要求显式同步。
- 本地实际安装：23 个入口、205 个文件，逐文件 SHA-256 核对，0 个差异；旧版保存在安装目录的 `.cs-skills-backups/`，工作树原文保存在 `.codex-checkpoints/`。
- 统一回归通过：静态结构、递归资源、安装器、代码叙事、产品包、13 项模型缓存、电商与 checkpoint 恢复。

## 验证边界

没有进行付费生图 / TTS / 视频生成，也没有重新下载大模型。文件一致性、脚本回归与发布状态不等同于新会话发现、模型判断或媒体人工审阅；安装后需打开新会话确认加载。

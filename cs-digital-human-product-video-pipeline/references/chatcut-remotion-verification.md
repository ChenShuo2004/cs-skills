# ChatCut、Remotion 与成片验收

## ChatCut 时间线结构

用语义角色检查，不假设任何项目中的固定轨道编号：

| 角色 | 应检查内容 |
| --- | --- |
| 主口播 | 覆盖完整脚本，音量稳定，无削波；实际音频与字幕时间对齐 |
| 数字人 / A-roll | 出场符合脚本，嘴型/声音匹配，画面无异常裁切 |
| 产品证据 B-roll | 每段口播有真实 UI、屏录、组件或原声证据；没有无关装饰镜头替代证据 |
| 字幕与重点词 | 逐句校正产品名、术语和 CTA；字幕不越界、不遮挡关键 UI |
| PIP | 只在需要讲解时出现；位于左下安全区，不遮挡字幕、产品按钮、关键数据或 Logo |
| SFX / BGM | SFX 只用于点击、切换或重点提示；BGM 轨为空或静音，除非产品包明确覆盖 |

## 圆形 PIP 透明通道回退

当 ChatCut 原生圆角、遮罩或嵌套层在合成预览中显示空层时：

1. 先确认源人物素材本身在独立预览中可见。
2. 删除空层和测试遮罩，避免把不可见层遗留在时间线。
3. 用 FFmpeg 预合成透明通道人像，保留 alpha，并记录中间文件格式、帧率与合成参数。
4. 将透明通道片段作为普通 PIP 素材重新放入左下安全区。
5. 在 PIP 进入后的两个独立时段截取合成帧，检查人物可见、圆形边缘自然、alpha 没有黑底或空层。
6. 对这两帧分别核对字幕、产品 UI、按钮、Logo 和演示重点均未被遮挡。

若透明通道在当前 ChatCut 项目不受支持，停止并报告兼容性阻塞；不要把方形人物、静态占位图或空层当作修复结果。

## Remotion 合成验收

渲染前后分别抽取关键帧，至少覆盖 Hook、每一产品证据章节、PIP 两个独立可见时段、总结和 CTA。

逐帧检查文字、产品名、进度、CTA、人物、字幕、安全区、切换边缘和 UI 可读性。持帧、CTA 或 Logo 停留要求连续帧哈希不漂移；不要只凭单帧判断稳定性。

## FFmpeg 与音频验收

使用 ffprobe 检查：

- 分辨率、帧率、总时长、视频编码和音轨；
- 默认规格为 1920×1080、30fps、55–60 秒、H.264；
- 有主口播音轨，且没有未授权的 BGM。

使用波形、响度或听检确认：

- 口播全程可懂、无明显削波、没有被 SFX 压住；
- SFX 仅在标注事件出现；
- 静音观看仍可通过逐句字幕和产品画面理解核心功能。

QA 报告需要把每项验收写为 passed、failed 或 not-applicable，并记录证据位置、检查者和修复链接。

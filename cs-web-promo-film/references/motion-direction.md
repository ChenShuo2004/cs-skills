# 网页宣传片的动效导演 brief

当用户要求更强的动效质感，或给了参考片时使用。先读参考、写导演 brief，再写 `PromoFilm.tsx`。参考只提供运动和节奏目标；片中的产品页面仍须来自真实截图。

## 输入与节拍

从参考片提炼可描述的特征：观众先看哪里、镜头何时停、哪个动作承担重点、色彩和声音怎样服务它。不要照搬参考的页面、Logo、文案或有版权的音频。没有参考时，用本片产品最重要的一次「发现 → 聚焦 → 点击/揭晓」作为主事件。

有 BGM 时，先记拍点或关键声音事件，再排动作；没有 BGM 时，先按观众读完页面和字幕所需的时间排节奏，不凭空假设音乐。需要用帧定位时，按 `秒 × fps` 换算。重动作可以落在拍点，预备、冲击、余韵应错开；不必每拍都动。

## 最小 brief

写在工程的分镜旁，字段可按片子精简：

| 字段 | 要回答的问题 |
|---|---|
| 核心与受众 | 观众看完只记住哪个产品价值？ |
| 参考 | 哪些镜头、节奏或材质值得借鉴？来源是什么？ |
| 镜头任务 | 每段让观众看哪个真实页面区域，停留多久？ |
| 主次层 | 页面/窗口、文案、指针、背景、光影谁先动，谁回应？ |
| 事件时间 | 预备、主动作、停顿、响应、转场分别在哪些帧？ |
| 运动原因 | 推近是为了读哪个元素？点击后为何切到下一页？ |
| 声音 | 用户要求音轨时，BGM 管情绪，SFX 只标注点击/揭晓等事件；默认无音轨。 |
| 禁止项 | 哪些常见效果会破坏产品可信度或阅读，例如全层同步淡入、持续漂移、过强辉光？ |
| 验收帧 | 每个主事件前、发生时、后，以及转场中点各看哪一帧？ |

## 让运动有主次和因果

- 同一时刻只设一个主事件。窗口先落位，页面停下来供阅读；指针和高亮在观众理解目标后再出现。背景和光影只支撑视线，不与产品抢注意。
- 同一事件可让主体、文案、指针、投影晚几帧依次响应；不要给所有层共用一条进度曲线。错相的目的在于表现「发起 → 回应 → 收束」，不是随机延迟。
- 对快速移动，可用轻微加速、减速与回稳表现重量。过冲和回弹只用在合理对象上，幅度要小；虚拟浏览器窗口不应像橡皮球。相机运动沿用 [camera.md](camera.md) 的同一组几何 `stops`，不要为追求错相把缩放、滚动和平移拆成互相漂移的轨迹。
- 光影方向保持一致；窗口位移时，投影与 halo 跟随窗口。避免整幅画面一起抖或用辉光掩盖对比度不足。
- 保持「真实页面截图」边界：可以运镜、叠加外部标题与真实链接的指针提示，不能让截图中的产品控件形变、重绘、凭空触发未拍到的交互。

## 事件验收

除了每段中点，给每个主事件抽 `前 → 中 → 后` 三帧，再看转场中点；有突兀动作时逐帧定位。检查主体是否清楚、次层是否响应、运动是否连贯、页面是否可读，以及点击是否对准实测链接。声音存在时核对 SFX 是否贴合接触帧且不盖过口播。不能用代码行数、特效数量或渲染成功代替实际画面判断。

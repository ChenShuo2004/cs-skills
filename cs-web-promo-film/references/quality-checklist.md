# 交付前自检清单

## 真实性

- [ ] 片中所有页面内容都来自 Playwright 采集的截图，没有用 HTML/CSS 重画的产品界面。
- [ ] 没有手打页面上不存在的文案冒充截图内容。
- [ ] 指针只点在真实存在的链接上，高亮框对齐真实元素边界。
- [ ] 出镜页面匿名访客都能打开，没有登录态、付费态才有的内容。
- [ ] 没有日更、黄历、个性化推荐等会过期的模块入镜。
- [ ] 片中数字能从公开页重新拉出来，与常量一致，并记下采集日期。
- [ ] 隐藏的浮层和调过的曝光都在交付说明里写明。
- [ ] 多画幅时横竖屏叙事、字幕、数字口径一致；竖屏不是横屏裁切。

## 取景

- [ ] 每段抽了静帧并**实际看过图**，不是只确认渲染成功。
- [ ] 没有网格被裁半列、侧边栏被切一半、卡片露出断口。
- [ ] 滚动终点没有滚过页面末尾露出空白。
- [ ] 屏幕文案与窗口没有叠压，文字没有压在页面截图的文字上。
- [ ] 推进后的内容在 1080p 下能看清，不是一团糊。

## 节奏

- [ ] 用户要求高级动效或提供参考片时，导演 brief 写明观看主次、主事件、层间响应、禁止项和验收帧。
- [ ] 关键事件的前、中、后帧都实际看过；主事件清楚，次层响应有因果，没有全层同步或无目的的持续运动。
- [ ] 每段静止时长足够读完屏幕文案（正文行 6 秒起）。
- [ ] 换文案发生在镜头停住时，不在推进过程中。
- [ ] 转场长度 30–80 帧（60fps 下 0.5–1.3 秒）。
- [ ] 镜头不是全程在动，有明确的停顿点。
- [ ] 开场 3–4 秒内出现品牌标识，收尾留 2 秒以上的静止落版。

## 明暗

- [ ] `luma-sweep` 扫过，转场处**没有**局部亮度低谷。
- [ ] 全片明暗比在 4 倍以内。
- [ ] 暗段平均亮度不低于 28。
- [ ] 浅色页面压过曝光（0.93–0.95），切过去不闪。
- [ ] 近黑的产品页在深色画布上有 halo 和投影托底，没有糊进背景。

## 规格

- [ ] `ffprobe` 确认分辨率、帧率、总帧数 = 预期时长 × fps。
- [ ] 音轨状态符合要求（默认无音轨，静音 AAC 轨要用 `-c:v copy -an` 剥掉）。
- [ ] `tsc --noEmit` 通过。
- [ ] 中文字体正确渲染，没有回退成默认字体或出现方框。

## 口播（若有）

- [ ] 口播没有复述屏幕上已有的字。
- [ ] 每句语速落在 3.8–4.5 汉字/秒。
- [ ] 口播不压在转场上，每段留了头尾余量。
- [ ] 画面里与口播重复的正文行已删除。
- [ ] `VO.md` 含连读版、对轨版、录音提示、备选开场。

## 交付物

- [ ] 成片路径与规格已说明（分辨率/帧率/时长/音轨/体积）。
- [ ] 每张截图对应的来源 URL 已列出。
- [ ] 改时长、改文案、改运镜的入口文件已说明。
- [ ] 已知边界已写明，没有把未解决的画面问题当作「已知瑕疵」蒙过去。
- [ ] 工程目录不含临时静帧、缩略图和调试产物。
